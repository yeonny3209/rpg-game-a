## 실행·테스트 방법
서버는 켜 둔 상태야(`tools\run-server.cmd`). http://localhost:7777 접속 후 **Ctrl+F5**.

1. **성별 선택** → 닉네임 **세윤**(관리자)으로 접속하면 개발 명령을 쓸 수 있어. 다른 닉네임은 일반 플레이.
2. Enter → `/레벨 5` → Enter (스탯 포인트 20개가 생겨)
3. 마을 **동쪽 수련장**(이장 집에서 오른쪽 앞, 마커 `!` 가 뜬 검술 스승·궁술 스승)에서 **V** → 시험 → 시험관을 쓰러뜨리기. 시험 중엔 첫 스킬(Q)을 빌려 써. 이기면 전직.
4. `/레벨 25` → 스킬 6개 전부 써 보기(Q E T G Z X). 스킬 창 K.
5. 궁수: 좌클릭 누르고 있다 떼기(차징 색 변화), 5발 쏘면 장전, 우클릭 조준 확대.
6. 검사: 우클릭 구르기, 수련장 허수아비를 쳐서 훈련량(스킬 창에 표시).
7. P: 스탯 `+` 후 `적용`. O: 설정(쿼터뷰·키 바꾸기). Enter: 채팅(한글).
8. 멧돼지·숲거미·갈색곰(남·동·북동 쪽 들판)에게 맞아 보면 넉백·둔화·기절이 나와.

되돌리기: `/직업초기화`, `/레벨 1`.

## 남은 문제
1. **브라우저 확인 전**: 키 입력·카메라·UI 배치·채팅 입력창은 실제로 눌러 봐야 알 수 있음.
2. 속성 상성·후방 2배는 아직 쓰는 쪽이 없음(마법사·암살자는 2b).
3. 새 몬스터 모델은 임시(늑대 도형), 스킬 이펙트는 단순한 도형.
4. 시험관이 스승 모델과 같은 임시 모델(경비병).
5. 스탯 초기화 UI는 없음(개발 명령만).
6. 이전에 말한 "다른 플레이어 레벨 갱신" 문제는 그대로.
