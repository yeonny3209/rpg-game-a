**상태: 기획자 확인 대기 (2026-11-07)**

## 실행·테스트 방법

1. `tools\run-server.cmd` 더블클릭 → DB가 자동으로 켜지고 `listening: http://localhost:7777`.
2. 브라우저에서 http://localhost:7777 → 닉네임 → 접속.
3. 해 볼 것:
   - 이장(보라색, 머리 위 노란 **!**)에게 가서 **V** → 대화 → 몽둥이 받기 → 퀘스트 수락.
   - 마을 남쪽 들판의 토끼를 **좌클릭**으로 사냥 (화면을 한 번 클릭해 마우스를 잠근 뒤). 토끼 간이 모이면 오른쪽 위 추적창 숫자가 오름.
   - 10개를 모으면 이장 머리 위가 **?** → 보고 → 2레벨, 장비·마을 밖 해금.
   - 보고 전엔 울타리 밖으로 못 나감(이장 대사가 뜸). 보고 후엔 나갈 수 있음.
   - 남서쪽 끝의 **회색 늑대(Lv5, 선공)** 에게 일부러 져 보기 → 사망 화면 → 3초 뒤 "마을에서 부활".
   - **I** 가방, **P** 캐릭터 창(보고 전엔 장비 칸이 잠겨 있음).
   - 창을 닫고 다시 접속 → 레벨·가방·퀘스트가 그대로인지.
4. 봇이 퀘스트를 깨는 모습 보기: 명령 프롬프트에서 `tools\run-bots.cmd 3 --hunt`.
5. 자동 테스트: `tools\run-tests.cmd`.

## 내가 정한 것 (확정 아님, 바꾸고 싶으면 말해 줘)

- **막타 루팅**: 드롭은 땅에 떨어지지 않고 막타 친 사람 가방으로 바로 들어감. 경험치도 막타만 (로드맵 1단계 "막타 루팅"). 파티 분배는 파티 단계에서.
- **하이트맵 내보내기 대신**: 로드맵엔 "지형 높이맵 내보내기"가 있지만, 맵 JSON 숫자로 서버·클라가 같은 지형 함수를 계산하게 했어. 파일이 필요 없고 항상 일치함. 실제 지형 에셋이 생기면 그때 높이맵 방식으로 바꿈.
- **데미지 숫자 색**: 일반 흰색, 치명타 노랑(5권 12.4 제안 그대로), 내가 맞은 숫자는 빨강(기획서에 없음).
- **I / P 키**: 기획서 키 배치에 가방·캐릭터 키가 없어서 비어 있는 I, P로 정함.

### 확인 중 고친 버그 3개
1. **고해상도 화면에서 UI가 화면 밖으로 밀림**: 페이지가 Unity에 실제보다 낮은 화면 배율을 넘기면 HUD·창이 잘렸음. 이제 실제 배율을 넘기고, 3D 해상도는 그만큼 낮춰서 **부담은 단계 0과 같게** 유지 (UI 글자만 선명해짐).
2. **접속 직후 땅 밑으로 떨어져 서버 보정 1~2회**: 막 만든 지형 충돌체가 물리에 반영되기 전에 떨어지던 문제. 고친 뒤 보정 0건.
3. **지붕 위에 올라가면 서버가 "너무 높다"고 끌어내림**: 서버가 건물 높이를 몰랐음. 이제 서버·클라가 같은 건물 수치로 지붕 높이를 계산 (테스트 추가).

## 남은 문제

1. **FPS 재측정 필요**: 이 PC의 확인용 브라우저 창은 백그라운드 취급이라 FPS가 의미 없음. 세윤 PC에서 F3 → FPS·worst(5s) 숫자를 알려 줘 (Low 기본). 단계 0 때 숫자를 안 남겨서 이번엔 기록하고 싶어.
2. **스탯 포인트는 쌓이기만 함**: 분배 UI는 로드맵상 단계 2a.
3. **임시 모델**: 캡슐·박스·구 조합. 아트는 나중 단계.
4. **다른 플레이어의 레벨 변화**는 다시 보일 때(재접속 등)만 갱신됨. 파티 단계 전에 고침.
5. 빌드 한 번에 약 35분(링크 단계가 느림). 클라이언트 수정은 묶어서 빌드할게.
