# 개발 로드맵

작성: 2026-11-05 · 기준: 기획서 5권 13장 · 기술 설계: [02_기술설계.md](02_기술설계.md)

## 공통 규칙 (모든 단계)

- 단계마다 **기획자가 직접 플레이해서 확인**할 수 있는 상태로 끝낸다. 보고서에는 만든 것, 실행·테스트 순서, 남은 문제, 다음 계획을 쓴다.
- **성능 회귀 체크**: 단계가 끝날 때마다 Iris Xe 브라우저에서 낮음 옵션 30fps를 다시 잰다. 떨어지면 다음 단계로 가기 전에 고친다.
- **서버 자동 테스트**: 공식·드롭·잠금처럼 확률과 동시성이 걸린 로직은 단위 테스트를 같이 만든다.
- 새로 넣는 [수치]는 전부 `data/` 테이블에 넣는다. 미결 사항에 닿는 기능은 구현 전에 질문한다.
- 그래픽은 단계 5까지 임시 도형이나 무료 에셋을 쓴다. 시스템이 먼저다.

크기 표기: S = 며칠, M = 1~2주, L = 몇 주 이상 (1인 + Claude 기준의 대략적인 감).

## 단계 0 · 기술 검증

**목표**: 웹 + 3D + 온라인 조합이 이 PC에서 돌아가는지 가장 먼저 확인한다.

**완료 기준**
- 브라우저에서 WebGL 빌드에 접속 → 3인칭 캐릭터로 WASD 이동, 마우스 카메라, 점프·더블 점프·활공·대시가 된다.
- 탭 2~4개(또는 봇 3개)를 띄우면 서로 움직이는 게 부드럽게 보인다.
- 서버가 비정상 속도(예: 순간이동 치트)를 보정해 되돌린다.
- **Iris Xe 브라우저, 낮음 옵션, 테스트 맵(지형 + 나무 수십 그루 + 4명)에서 30fps 이상**. FPS 오버레이로 확인한다.

**작업**
- [M] Unity 프로젝트 생성, URP 품질 3단계, WebGL 설정, DPR 상한, FPS 오버레이
- [M] 3인칭 캐릭터 컨트롤러 + Cinemachine 카메라, 이동 수치는 `game_config.json`
- [M] `shared` 패키지: 프로토콜, NetWriter/Reader, 이동 규칙 상수
- [M] .NET 서버: WebSocket 접속, ZoneInstance 20Hz 틱, 스냅샷 전송, 이동 검증·보정
- [S] 클라 네트워크: 에디터·WebGL 전송 계층, 원격 엔티티 100ms 보간
- [S] BotClient, 로컬 실행 스크립트(서버 + WebGL 로컬 웹서버)

## 단계 1 · 시작 마을

**목표**: 접속 → 이장 대화 → 토끼 사냥 → 퀘스트 완료 → 2레벨 → 장비·맵 해금까지 온라인으로 동작한다.

**완료 기준**
- 닉네임으로 접속하고, 껐다 켜도 레벨·인벤토리·퀘스트 진행이 남아 있다(PostgreSQL).
- 이장 대화(V키) → 나무 몽둥이가 자동 장착된다. 장비창은 잠겨 있다.
- 토끼는 비선공이고, 맞으면 약하게 반격한다. 1~3골드, 토끼 간 70%, 토끼 발 10%가 드롭되고 5초 뒤 리스폰한다(전부 데이터 테이블).
- "토끼 간 10개" 완료 → 2레벨, 장비창 개방, 마을 경계 해제(그 전에는 이장이 막는 연출).
- 레벨 1~5 경험치 표, 평타 전투(서버 판정, 데미지 숫자), 어그로(마지막 공격자, 귀환 거리 넘으면 복귀하며 회복).
- 선공 늑대(Lv5)에게 죽으면 → 패널티 없이 마을에서 부활.
- 2명 이상이 같은 토끼를 때릴 때 막타 루팅, 드롭은 서버만 결정.

**작업**
- [M] DB 스키마(계정→캐릭터, 스탯, 인벤토리, 장비, 퀘스트 진행, 유지 조건용 시각 기록), 마이그레이션
- [M] 데이터 테이블: exp_table, stats, items, monsters, monster_stats, spawns, drop_tables, npcs, dialogues, quests + 검증기
- [M] 몬스터 AI(비선공·선공·어그로·귀환), 스폰·리스폰
- [M] 전투 1차: 평타 판정(도형), 데미지 공식 기본형(4권 1.1 중 공격력·방어 감소·무작위), HP, 사망·부활
- [M] 퀘스트 시스템 기본(수집·처치·대화 목표, 보상), 대화창 UI
- [S] HUD(HP 바, 경험치, 골드, 퀘스트 추적), 인벤토리 UI(보기만), 레벨업 스탯 포인트 누적
- [S] 지형 높이맵 export → 서버 이동 검증에 반영

## 단계 2a · 1차 전직 틀 + 직업 2종

**목표**: 전직·스킬·스탯 시스템을 완성하고, 근접 1종 + 원거리 1종으로 손맛을 확정한다.

**완료 기준**
- 5레벨 → 스승 NPC의 전직 시험 → 동양 검사 또는 궁수 전직(나머지 직업은 "준비 중").
- 스탯 5종 분배 UI, 스탯 효과·전투 스탯(치명·관통·CC 저항 등) 적용.
- 스킬 6칸(QETGZX), 쿨타임 서버 검증, 숙련도로 스킬 레벨이 오름(적중 시에만).
- 궁수: 차징 100/200/300%, 풀차징 관통 20%, 탄창 5발·장전 2.5초, 차징 중 이속 80, CC 맞으면 차징 취소.
- 동양 검사: 훈련량 누적, 수련장 하루 상한.
- 후방 120° 판정, CC 5종 + CC 후 3초 면역, 속성 상성표.
- 쿼터뷰 카메라 + 설정 메뉴(그래픽 품질, 카메라 전환, 키 재배치), 일반·월드 채팅.

**작업**: [L] 스킬 프레임워크(데이터 주도: 판정 도형, 계수, CC, 투사체), [M] 전직 퀘스트, [M] 직업 2종 스킬 각 6개, [M] 스탯·전투 스탯, [S] 채팅, [M] 설정·쿼터뷰, [S] 1~12레벨 사냥용 몬스터 3~4종 추가

## 단계 2b · 나머지 기본 직업 5종

**목표**: 기본 직업 6종(7갈래) 모두로 사냥할 수 있다.

**완료 기준**: 서양 검사(마나 주입 토글), 마법사(속성 선택·서클 1~4 자동 승급·비행), 암살자(그림자 걸음·후방 2배), 전사(도발·방패), 버퍼(신성력·설교·파티 버프·대상 힐 F1~F6·부활)로 각각 5→12레벨 사냥이 된다.

**작업**: [L] 직업별 스킬·고유 수치, [M] 비행(지속·쿨·피격 추락), [M] 임시 파티(버퍼 테스트용 최소 기능)

> 마법사 속성 선택은 **미결 1**에 닿는다 → 단계 2b 시작 전에 질문한다.

## 단계 3 · 아이템과 경제

**목표**: 골드와 아이템이 서버에서 안전하게 흐르고, 모든 변동이 로그에 남는다.

**완료 기준**
- 장비 슬롯 전체, 7등급 + 랜덤 옵션(줄 수, 재설정), 직업 전용 무기 제한.
- 인벤토리 40칸·확장, 창고, 999개 겹치기, NPC 상점(구매·10% 판매), 포션(쿨 없음).
- 무기 강화 +15(+10부터 파괴, 파괴 방지 주문서), 등급 진화(확률, 강화 수치 유지). 결과는 서버만 결정한다.
- 교환창(양쪽 확인, 골드 2% 수수료), 우편, 경매장(즉시구매, 수수료 8%, 48시간, 정산은 우편).
- 두 명이 동시에 같은 경매 물건을 사도 한 명만 성공한다(테스트).
- 운영자 화면 기초: 골드 생성·소멸량 집계.

**작업**: [M] 아이템 인스턴스·옵션 모델, [M] 상점·인벤토리·창고 UI, [M] 강화·진화, [M] 교환·우편, [M] 경매장, [S] 감사 로그·집계

> 방어구·장신구 강화 범위는 **미결 2**, 토끼 간 거래 여부는 결정기록 보류 항목 → 단계 3 시작 전에 질문한다.

## 단계 4 · 월드 확장 + 첫 원격 지인 테스트

**목표**: 시작 지역 밖으로 세계가 넓어지고, 지인이 원격으로 들어와 같이 논다.

**완료 기준**
- 지역 2(중앙 도시 솔라)·3(안개 폭포 계곡)·4(고목의 숲), 지역 간 로딩, 마을 간 텔레포트.
- 몬스터 등급(일반·엘리트·네임드·보스), 레벨 색 표시, 정기 필드 보스(전조 표시·페이즈), 던전 2개(토끼굴 지하, 도적 소굴).
- 파티 6명(모집 게시판·초대), 기여도 경험치 분배(최소 10% 보장), 루팅 방식 선택.
- 낮밤(현실 2시간 주기), 날씨, 일식(30분마다 3분).
- **메인 퀘스트 1~3장 + 진영 선택**, 지역 서브 퀘스트 연작, 마을 게시판 일일·주간 의뢰, 필드 돌발 의뢰.
- **실제 계정(아이디·비밀번호), 캐릭터 3슬롯, 캐릭터 커스터마이징(성별·얼굴·머리 프리셋)**.
- **Cloudflare Tunnel로 기획자 PC 서버를 외부에 공개(wss, 비용 0원)** → 지인 3~5명이 원격으로 1시간 플레이테스트 → 피드백 정리.

## 단계 5 · 성장 후반

**목표**: 50레벨까지 갈 수 있다.

**완료 기준**: 30·50 전직 + 궁극기(R, 30 획득 → 50 교체), 2·3차 스킬, 스킬 진화(레벨 10, 1회), 마법사 서클 5~7 전투 시험(1:1 인스턴스), 히든 스킬 틀(F키, 여러 개 보유·1개 장착) + 조건이 준비된 히든 스킬, 지역 5~8, 던전 나머지, 메인 퀘스트 4~6장. 경험치 곡선 원칙(하루 1시간 유저가 주 1레벨)을 봇 시뮬레이션이나 실측으로 확인한다.

## 단계 6a · 유일한 자리 + 대표 히든

**목표**: "월드에 한 명뿐"인 자리가 절대 중복되지 않음을 증명한다.

**완료 기준**
- `unique_slots` 잠금, 시련 선점, 연결 끊김 5분 유예, 실패 시 캐릭터 단위 영구 불가.
- **동시성 테스트**: 스레드 100개(또는 봇 100개)가 같은 드래곤을 동시에 노리면 정확히 1명만 성공한다. 자동 테스트로 상시 실행한다.
- 용기사 일반 1종(불): 하늘 드래곤 출현, 시련(잿불 수호자), 계약, 친밀도·선물·대화·드래곤 퀘스트, 스킬 습득.
- 유지 조건 3종(OR) + 경고(3일·1일 전, 12시간 배너) + 24시간 유예(월 1회) + 해지 시 동굴 재개방.
- 마검사: 이장 집 열쇠 → 진짜 폭포 → 전직, 전용 마법서, 콤보 캔슬.
- 개발용 서버 시간 조작 명령.

> 마검사 폭포 개수·위치는 **미결 6** → 단계 6a 시작 전에 질문한다.

## 단계 6b · 나머지 히든
